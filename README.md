# 🚁 Sistema de Control de Enjambres

Sistema web desarrollado en **PHP** para el control, monitoreo y gestión de enjambres de drones orientados a la supervisión automatizada de campos de cultivo.

> 🎓 **Proyecto académico desarrollado para estudiantes de la Universidad Tecnológica de Panamá (UTP).**

---

## 📋 Descripción

El proyecto presenta una solución orientada a la **gestión inteligente de múltiples drones**, permitiendo coordinar sus operaciones, monitorear su estado y apoyar la detección de plagas en áreas agrícolas.

La aplicación busca demostrar conceptos de **programación, arquitectura de software, automatización y gestión de sistemas distribuidos** mediante un escenario de uso basado en agricultura inteligente.

---

## ✨ Características

* 🚁 **Control de enjambre distribuido**

  * Coordinación de múltiples drones.
  * Gestión de operaciones autónomas.

* 🧭 **Navegación adaptativa**

  * Optimización de rutas.
  * Gestión de desplazamiento del enjambre.

* 📡 **Monitoreo**

  * Visualización del estado de los drones.
  * Seguimiento de las operaciones del enjambre.

* 🦗 **Detección de plagas**

  * Identificación de posibles zonas afectadas.
  * Apoyo al control de langostas en cultivos.

* 🌱 **Agricultura inteligente**

  * Automatización de tareas de supervisión.
  * Aplicación de tecnología al monitoreo agrícola.

El sistema está desarrollado siguiendo principios de **Programación Orientada a Objetos (POO)**, buscando mantener una estructura modular y facilitar la separación de responsabilidades.

                    └──────────┬──────────┘

              ┌────────────────┼────────────────┐
              │                │                │

        ┌───────────┐    ┌───────────┐   ┌────────────┐

                    ┌─────────────────────┐

                    └─────────────────────┘

El objetivo es aplicar conocimientos de:

* Programación Orientada a Objetos
* Desarrollo web
* Diseño de sistemas
* Gestión de información
* Automatización
* Modelado de sistemas
* Resolución de problemas mediante software

## 🚀 Ejecución

Clona el repositorio:

```bash
git clone <repository-url>
```

Accede al proyecto:

```bash
cd sistema-control-enjambres
```

Si utilizas un servidor local como **XAMPP**, coloca el proyecto dentro de:

```text
htdocs/
```

Luego inicia:

```text
Apache
```

Y accede desde:

```text
http://localhost/sistema-control-enjambres
```
